# 🚀 Portfolio Plan — Full-Stack Dev | Glassmorphism / Futuristic

---

## 🎨 Design Direction

| Property       | Value                                                                 |
|----------------|-----------------------------------------------------------------------|
| **Theme**      | Glassmorphism + Futuristic Dark                                       |
| **Background** | Deep space dark (#0a0a0f) with animated gradient mesh / aurora blobs |
| **Glass Cards**| `backdrop-filter: blur(16px)` + `rgba(255,255,255,0.05)` borders     |
| **Accent**     | Electric cyan `#00f5ff` + violet `#7c3aed`                           |
| **Typography** | Display: `Orbitron` or `Space Grotesk` — Body: `DM Sans`             |
| **Motion**     | Staggered fade-in on scroll, floating blobs, cursor glow effect       |

---

## 📐 Page Structure

```
[ Navbar ]
[ Hero ]
[ About Me ]
[ Skills ]
[ Projects ]
[ Contact ]
[ Footer ]
```

---

## 🧩 Section Breakdown

### 1. Navbar
- Fixed / sticky, glass blur background on scroll
- Logo (your name or initials) on the left
- Nav links: About · Skills · Projects · Contact
- CTA button: **"Hire Me"** or **"Download CV"** (pill shape, glowing border)

---

### 2. Hero Section
- Full-viewport height
- Big headline: `"I Build Things for the Web."` or your tagline
- Sub-text: role description (Frontend + Full-Stack Dev)
- Two CTAs: **"See My Work"** → Projects | **"Let's Talk"** → Contact
- Background: animated gradient blobs / aurora / particle mesh
- Optional: floating 3D badge or avatar with glow ring

---

### 3. About Me
- Two-column layout:
  - **Left**: Profile photo with glass card frame + glow border
  - **Right**: Short bio (3–4 lines), key facts (location, experience, open to work)
- Personality note: "I can build anything — full-stack web apps, APIs, dashboards — except ML."
- Download Resume button

---

### 4. Skills
- Grid of glass pill / badge cards per skill
- Grouped into categories:
  - **Frontend**: React, Next.js, Tailwind, TypeScript, HTML/CSS
  - **Backend**: Node.js, Express, REST APIs, GraphQL
  - **Database**: MongoDB, PostgreSQL, Firebase
  - **Tools**: Git, Docker, Vercel, Figma
- Optional: animated progress bars or radar chart for proficiency

---

### 5. Projects
- Card grid (2–3 columns on desktop)
- Each card (glass morphism):
  - Project thumbnail / screenshot
  - Title + short description (1–2 lines)
  - Tech stack tags (small pills)
  - Two icon buttons: 🔗 Live Demo | 📁 GitHub
- Featured project: full-width hero card on top

---

### 6. Contact
- Glass card centered on page
- Headline: `"Let's Build Something Together"`
- Contact form: Name · Email · Message · Send Button
- OR: just social links + email if no backend
- Social icons: GitHub · LinkedIn · Twitter/X

---

### 7. Footer
- Minimal: your name + copyright
- Tagline: `"Crafted with curiosity ⚡"`

---

## 🛠 Tech Stack Recommendation (for building it)

| Layer      | Choice                          |
|------------|---------------------------------|
